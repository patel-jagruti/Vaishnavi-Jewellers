# Visnavi Jwallers (Local)

This is a small PHP demo storefront. Quick steps to run locally using XAMPP on Windows:

1. Place the project in your XAMPP `htdocs` folder (already located at `c:/xampp/htdocs/visnavi-jwallers`).
2. Start Apache from the XAMPP Control Panel.
3. Open the site in your browser:

```
http://localhost/visnavi-jwallers/
```

Notes:
- The hero images are placeholders in `assets/images/*.svg`. Replace them with real images (keep names or update `index.php`).
- Search suggestions use `api/products.php` which reads `includes/products.php`.

To commit changes locally (already committed in this workspace):

```
git add .
git commit -m "Your message"
```
